Cybersecurity Internship from Elevate Labs  
Project: Password Strength Analyzer with Custom Wordlist Generator

Objective:
Build a tool to analyze password strength and generate custom wordlists.

Tools Used:
1. Python – Main programming language used for developing the project
2. zxcvbn – Password strength estimation and feedback
3. NLTK – Text processing and tokenization
4. argparse – Command-line interface development
5. Tkinter – Graphical user interface development
6. pytest – Testing and verification
7. Visual Studio Code – Development environment

What I Did:
*Set up the Python environment and installed the required libraries.
*Developed a password analyzer using zxcvbn with strength ratings, feedback and basic pattern checks.
*Created a custom wordlist generator using name, pet name, year and phrase inputs with different variations and combinations.
*Added an option to limit and save the generated wordlist as a .txt file.
*Created both CLI and Tkinter GUI interfaces for the project.
*Tested the main features using pytest.

Key Concepts Learned:
*Password strength analysis
*Password security and predictability
*Common password patterns
*Custom wordlist generation
*Command-line interface development
*GUI development using Tkinter
*Python modular programming
*Unit testing with pytest
*Basic cybersecurity tool development
